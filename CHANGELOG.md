# Changelog

## 0.1.0

Initial release candidate. Registry publication remains a separate maintainer action.

- Open local HTML and supported HTTP localhost applications.
- Send messages, annotations, exact-edit proposals, and structured form values.
- Preserve explicit form state and browser drafts.
- Deliver input with leases, receipts, and revision checks.
- Run the installed CLI with Node.js or Bun.
- Include examples, an agent skill, command documentation, and diagnostic commands.

This release does not include Markdown rendering, remote websites, cookie authentication, or MCP Apps.
