Comment markers stay pinned to their targets while the page scrolls. They stay inside a target whose text gets shorter, and use the bar's glass surface so they stay visible on dark pages. Feedback diffs collapse source indentation. The bar sits in the bottom-right corner and uses the same terms as the guides. Requests for an unknown session without the agent credential return 401 instead of 404.

The bar keeps clear of page scrollbars and does not jump when it opens or closes. Send shows an icon, a loader while sending, and a check after sending. The agent status dot has one color per state. Text fields use a softer focus outline. Long text diffs in the bar scroll. An HTML file page reloads on its own after its source changes. App pages show a **Refresh page** button.
