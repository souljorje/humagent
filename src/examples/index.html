Humagent Interactive demo

Show your agent what you mean

  1. Install

    npm i -g humagent
    npx skills add souljorje/humagent

  2. Connect

    Send this to your agent

    /humagent ./your-page.html

  3. Give feedback

    Comment on elements, rewrite text, and answer questions. Then send it to the agent.

Controls

Enter
Confirm a comment or edit
Shift Enter
Add a new line
Esc
Cancel
Arrow keys
Move between elements while annotating
⌘ or Ctrl Enter
Send from the bar

Your agent gets one structured feedback

Press Send, and your agent gets everything you marked, in order. It updates the page, then lets you know it is done.
